Phím tắt

Tóm tắt Ctrl+Shift+S
Affiliate Ctrl+Shift+A
Copy kết quả Ctrl+C
Sửa kết quả Ctrl+E

Đổi phím: chrome://extensions/shortcuts

Hướng dẫn

  1. Bôi đen chữ trên feed → chọn Tóm tắt / Status / Affiliate.
  2. Chỉnh sửa hoặc đổi tone → Copy hoặc Đăng Status.
  3. Paste link nguồn vào comment đầu (nút Paste trong panel).

Hỗ trợ: Facebook · Threads · X · LinkedIn · Reddit

Quyền tùy chọn

Chỉ xin clipboard, cookies Shopee và host HTTPS rộng khi bạn dùng tính năng đó lần đầu. Từ chối vẫn dùng được tóm tắt / status.

Tính năng chính

FeedWriter giúp bạn tóm tắt và viết lại nội dung từ mạng xã hội một cách thông minh.

  • ✓ Tóm tắt bài viết dài thành nội dung ngắn gọn
  • ✓ Phát hiện và ẩn bài quảng cáo, affiliate
  • ✓ Hỗ trợ đa ngôn ngữ (Việt, Anh, Trung, Nhật...)
